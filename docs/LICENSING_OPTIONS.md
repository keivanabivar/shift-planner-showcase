# Licensing decision pending

No final project license has been added. The owner must choose before publication. This page is a comparison, not a license grant. Dependency licenses remain separate and must be respected.

| Option | Practical effect | Suitable when |
| --- | --- | --- |
| MIT | Broad use, modification, redistribution and commercial use; retain copyright/license notice. Short and permissive; no express patent grant. | The owner wants straightforward open-source reuse. |
| Apache-2.0 | Broad reuse with an express contributor patent license and termination terms; license/notice and modification requirements apply. It does not grant trademark rights. | The owner wants permissive reuse with explicit patent terms. |
| Publicly visible, no broad reuse license | Default copyright applies. GitHub users can view/fork under its platform terms, but public visibility is not a general license to redistribute or commercialize the project. | The immediate goal is portfolio review while reuse rights remain undecided. |

For a showcase whose reuse policy is undecided, defer granting a license until the owner decides. If broad reuse is desired, MIT is the simpler default candidate; Apache-2.0 is appropriate when its patent terms and notice obligations are wanted. Neither permissive license requires derivatives to be open source.
