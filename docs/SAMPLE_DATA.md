# Sample-data policy

All test identities, organizations, employees, schedules, requests and identifiers are synthetic fixtures. They are not copied from operational records, backups, Auth exports or user guides.

Human-looking fixture names have been replaced with explicit `Demo` labels. Fixture emails use reserved example/test/invalid domains; form hints use illustrative addresses. The README separately lists the approved public maintainer contact. Short IDs and fixed UUIDs in tests are deterministic fixtures, not account exports. Passwords and invitation/session tokens in isolated tests are deliberately fake and are not usable against a hosted service.

Dates and schedules exercise month boundaries, archives, time calculation, concurrency and permissions. They are test inputs, not historical staff schedules. Do not replace them with real employee data.

The included Italian guide is a separately reviewed, sanitized copy with identifying fields neutralized. The original operational guide is excluded. Any future screenshot should show clearly marked demo data and a local/mocked development instance.
